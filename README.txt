GitHub Pages 배포용 전기기능사 모의시험

이 압축은 GitHub Pages에 바로 올리기 좋게 만든 버전이다.

파일
- index.html
- manifest.json
- service-worker.js
- icon.svg

가장 쉬운 사용법
1. 압축 해제
2. GitHub 새 저장소 생성
3. 안의 파일 4개를 저장소 루트에 업로드
4. Settings > Pages
5. Deploy from a branch
6. Branch: main / root 선택
7. 저장
8. 잠시 후 생성된 주소로 접속
9. 아이폰 Safari에서 열고 '홈 화면에 추가'

주의
- 파일앱 미리보기 말고 반드시 Safari 웹주소로 접속해야 한다.
- 오답노트/통계는 같은 브라우저의 로컬 저장소에 저장된다.
