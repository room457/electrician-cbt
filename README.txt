GitHub Pages 배포용 전기기능사 모의시험

이 압축은 GitHub Pages에 바로 올리기 좋게 만든 버전이다.

파일
- index.html
- manifest.json
- service-worker.js
- icon.svg

가장 쉬운 사용법
1. 압축 해제
2. GitHub 새 저장소 생성
3. 안의 파일 4개를 저장소 루트에 업로드
4. Settings > Pages
5. Deploy from a branch
6. Branch: main / root 선택
7. 저장
8. 잠시 후 생성된 주소로 접속
9. 아이폰 Safari에서 열고 '홈 화면에 추가'

주의
- 파일앱 미리보기 말고 반드시 Safari 웹주소로 접속해야 한다.
- 오답노트/통계는 같은 브라우저의 로컬 저장소에 저장된다.


v2 수정사항
- 다음/이전/답안표 이동 시 페이지 상단 강제 스크롤 제거
- 각 문항의 보기 순서를 시험 시작 시 랜덤 셔플
- 한 시험 안에서는 같은 문항의 보기 순서 고정


v3 추가사항
- 같은 개념 문항에 변형 버전을 추가하고 시험 시작 시 랜덤 선택
- 문항 순서 랜덤
- 보기 순서 랜덤
- 실전 기본값 60문항 / 60분 유지


v4 수정사항
- 다음/이전/답 선택/답안표 클릭 시 현재 스크롤 위치를 저장 후 즉시 복원
- 버튼 type=button 명시로 iPhone Safari 동작 안정화
